# 🎌 Anime Explorer

Anime Requester est une application web simple et interactive qui permet de rechercher des animes via l'API rapidAPI. L'utilisateur peut filtrer par titre, ID ou classement, et genre et visualiser les résultats sous forme de cartes détaillées.

---

## Fonctionnalités

- Recherche d'animes par **titre**, **ID** ou **classement**
- Mode clair/sombre avec mémorisation du thème
- Affichage des genres, synopsis, nombre d'épisodes et classement
- Saisie dynamique de la **clé API RapidAPI** via l'interface
- Stockage de la clé API en `sessionStorage` pour la session en cours
- Bouton de retour en haut de page
